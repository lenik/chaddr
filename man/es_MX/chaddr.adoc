== NAME

chaddr - change or reallocate profile-managed IP addresses

== SYNOPSIS

*chaddr* [_OPTIONS_] [_PROFILE_...]

== DESCRIPTION

*chaddr* reads one or more profile files and coordinates updates across cloud APIs, DNS/name servers, local *hosts*(5), and BIND zone files. Without CLI action flags it opens a graphical editor.

Profiles live in _~/.config/chaddr/profile_ by default. Override with the *CHADDR_PROFILE_DIR* environment variable. Example profiles ship in _/usr/share/chaddr/profile_ when installed from a package, or in _profile/_ in a source checkout. On first run, an empty user profile directory is seeded from those examples. Each profile lists resource blocks such as AWS Elastic IP, Namecheap registered nameservers, hosts files, and BIND db files.

== OPTIONS

*-c*, *--config* *_FILE_*::
  JSON configuration file with API keys and secrets. If omitted, *chaddr* searches for _./chaddr.conf_ and _~/.config/chaddr/chaddr.conf._
*--proxy _URL_*::
  HTTP or SOCKS proxy URL, for example _socks5://127.0.0.1:1080_.
*--diagnose*::
  Run diagnosis only and print results to stdout (CLI mode).
*-A*, *--addresses*::
  List all candidate addresses for each profile with source labels (_history_, _resolve_, _instance_, _old-ip_, etc.) and exit.
*--renew*::
  Reallocate elastic IP addresses and propagate changes (CLI mode).
*--apply _IP_*::
  Apply a new IPv4 or IPv6 address manually (CLI mode). Equivalent to *--apply-ipv4* when the value is IPv4.
*--apply-ipv4 _IP_*::
  New IPv4 address for manual apply.
*--apply-ipv6 _IP_*::
  New IPv6 address for manual apply.
*--old-ip _IP_*::
  Old IP to match when automatic detection fails during manual apply or diagnose.
*-v*, *--verbose*::
  Increase logging verbosity. Repeat for debug output.
*--no-gui*::
  Force CLI mode even when no action flag is given.

== CONFIGURATION

Configuration is JSON. Copy _chaddr.conf.template_ to _chaddr.conf_ and fill in credentials. Keys include AWS, Aliyun, and Namecheap API settings, optional *proxy,* and *client_ip* with a one-hour cache expiry when auto-detected.

Set *namecheap_whitelist* to _disabled_ (the default) to skip portal-based IP whitelisting. Set it to _portal_ to retry through the Namecheap web UI when API calls fail because the client IP is not whitelisted.

== PROFILES

Each profile file contains blocks such as:

____
....
description: Example relay
history-addr: 198.51.100.4 "2026-06-24 12:00:00"
history-addr: 2001:db8::1 "2026-06-24 12:00:00"

from: resolve
resolve: example.example.com

type: aws elastic ip
region: us-east-1

type: registered nameserver
api: namecheap
ns: ns1.example.com, ns2.example.com

type: hosts file
path: /etc/hosts

type: zone file
path: /var/cache/bind/db.example.com
....
____

*from: resolve* with a hostname to discover current addresses. Profiles may also use *from: ec2 nic* / *from: aliyun nic* (with *nic:* ENI id), or *from: ec2* / *from: aliyun* (aliases *ec2 instance* / *aliyun instance*; with *instance:* ID) to read public IPv4 from the cloud API. Prefer NIC scope when an instance has multiple ENIs; instance-scope renew only updates IPs present in *history-addr*. See *chaddr-profile*(5) for the full profile syntax, header fields, resource types, and examples. A trailing *\* continues a line on the next physical line. Spare addresses from earlier handlers or the GUI help match old IPs in hosts files, zone files, and plain *file* entries.

== GUI

The graphical interface lets you select profiles, manage a unified address list (with source labels), diagnose resources, renew elastic IPs, and apply manual changes. Address candidates load in the background when a profile is selected; use the stop control beside the progress bar to cancel. Apply and Renew open the Logging tab for the active profile. The profile list title shows the active directory, for example _Profile: ~/.config/chaddr/profile/_. Use *File → Browse...* to switch directories. Use *View → Right Pane* (*Ctrl+H*) to show logging and diagnostics tabs.

Writing protected files such as _/etc/hosts_ may prompt for elevation through *pkexec*(1), *gksudo*(1), or *kdesudo*(1).

== EXAMPLES

Diagnose a profile:

____
*chaddr --diagnose -v example*
____

Apply a new IPv4 manually:

____
*chaddr --apply 203.0.113.10 --old-ip 198.51.100.4 example*
____

Launch the GUI with profiles pre-selected:

____
*chaddr example*
____

== ENVIRONMENT

*CHADDR_PROFILE_DIR*::
  Directory containing profile files. Default: _~/.config/chaddr/profile/_

== FILES

_~/.config/chaddr/profile/_::
  Default profile directory.
_~/.config/chaddr/chaddr.conf_::
  User configuration file.
_./chaddr.conf_::
  Local configuration file in the current directory.
_/usr/share/chaddr/profile/_::
  Example profiles installed with the Debian package.
_/usr/bin/chaddr_::
  Installed command when built as a Debian package.
